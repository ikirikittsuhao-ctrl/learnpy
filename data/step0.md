# 01 プログラミングって何？

> **このページの学習目標**
>
> 「プログラミング」という言葉の基本的な意味を理解し、コンピューターに命令を与えるとはどういうことなのかを理解します。

---

## 1. プログラミングとは

プログラミングとは、

**「コンピューターに実行してほしい処理を、コンピューターが実行できる形の命令として順序立てて記述すること」**

です。

少し難しく感じるかもしれません。

簡単に言えば、

**「コンピューターにやってほしいことを、命令として書くこと」**

と考えてください。

例えば、人間に次のような指示をするとします。

1. コップを取る
2. 水を入れる
3. 水が入ったコップを机の上に置く

これは、人間に対する命令です。

コンピューターに対しても同じように、

1. データを受け取る
2. データを計算する
3. 条件を確認する
4. 結果を表示する

というように、実行してほしい処理を順番に指示します。

この「コンピューターに実行させる命令」を記述したものが、**プログラム**です。

そして、プログラムを書く作業が**プログラミング**です。

---

## 2. プログラムとは

プログラムは、コンピューターに実行させるための命令をまとめたものです。

例えば、電卓のようなプログラムを考えてみましょう。

ユーザーが、

```text
100 × 3
```

と入力したとします。

プログラムは、

1. 「100」という数字を受け取る
2. 「3」という数字を受け取る
3. 掛け算をする
4. 結果の「300」を表示する

という処理を行います。

つまり、プログラムは単に数字を表示しているだけではありません。

**入力を受け取り、何らかの処理を行い、その結果を出力する**

という流れがあります。

---

## 3. プログラミングは「命令の組み合わせ」

コンピューターは、プログラマーが書いた命令を組み合わせて処理を行います。

例えば、

```text
画面に「こんにちは」と表示する
↓
名前を入力してもらう
↓
入力された名前を保存する
↓
「こんにちは、○○さん」と表示する
```

という命令を順番に作ることで、簡単な会話プログラムを作れます。

一つ一つの命令は簡単でも、それらを組み合わせることで複雑な処理を実現できます。

例えば、

- 電卓
- ゲーム
- Webサイト
- スマートフォンアプリ
- 画像処理ソフト
- 動画編集ソフト
- AIシステム
- データ分析システム

なども、基本的には大量の命令を組み合わせて作られています。

---

## 4. 人間への指示とコンピューターへの指示

人間に指示する場合、ある程度あいまいな表現でも意味を理解してもらえることがあります。

例えば、

```text
「部屋をきれいにして」
```

と言えば、人間なら、

- ゴミを拾う
- 机を整理する
- 床を掃除する

などを考えて行動できるかもしれません。

しかし、コンピューターは「きれいにして」という言葉だけでは、具体的に何をすればいいのか判断できません。

そのため、コンピューターには具体的な命令が必要です。

例えば、

```text
1. ゴミの一覧を取得する
2. ゴミに分類されたデータを検索する
3. 該当するデータを削除する
4. 削除が完了したことを表示する
```

というように、実行する処理を具体的に指定します。

---

## 5. コンピューターは指示された通りに動く

プログラミングで非常に重要なのが、

**コンピューターは基本的に、プログラムに書かれている命令に従って処理する**

ということです。

人間なら、

```text
「たぶんこういう意味だろう」
```

と考えて補ってくれることがあります。

しかし、コンピューターはプログラムに書かれていないことを勝手に実行してくれるわけではありません。

そのため、プログラミングでは、

- 何をするのか
- いつするのか
- どの順番でするのか
- どの条件で実行するのか
- どのデータを使うのか

などを明確に指定する必要があります。

---

## 6. プログラムの基本「入力 → 処理 → 出力」

多くのプログラムには、

**入力 → 処理 → 出力**

という基本的な流れがあります。

### 入力（Input）

プログラムが外部から情報を受け取ることです。

例えば、

- キーボードから文字を入力する
- マウスをクリックする
- ファイルを読み込む
- センサーからデータを受け取る
- Webサイトからデータを取得する

などがあります。

---

### 処理（Process）

入力されたデータを使って、何らかの作業を行います。

例えば、

- 計算する
- 比較する
- 検索する
- 並べ替える
- データを加工する
- 条件を判断する

などです。

---

### 出力（Output）

処理した結果を外部へ出します。

例えば、

- 画面に文字を表示する
- 計算結果を表示する
- ファイルに保存する
- 音を鳴らす
- プリンターで印刷する

などがあります。

---

## 7. 「入力 → 処理 → 出力」の具体例

例えば、100円の商品を3個購入するプログラムを考えます。

### 入力

```text
商品の価格 = 100円
購入数 = 3個
```

### 処理

```text
100 × 3
```

### 出力

```text
300円
```

Pythonで書くと次のようになります。

```python
price = 100
count = 3
total = price * count

print(total)
```

実行すると、

```text
300
```

と表示されます。

このプログラムも、

```text
入力
↓
価格と個数
↓
処理
↓
掛け算
↓
出力
↓
300
```

という流れになっています。

---

## 8. プログラムには「順番」がある

プログラムでは、命令をどの順番で実行するかが非常に重要です。

例えば、

```text
1. 水をコップに入れる
2. コップを取る
```

では、自然な動作になりません。

普通は、

```text
1. コップを取る
2. 水を入れる
```

という順番にします。

プログラムでも同じです。

例えば、

```python
price = 100
count = 3
total = price * count

print(total)
```

では、

1. priceに100を保存する
2. countに3を保存する
3. priceとcountを掛ける
4. 結果をtotalに保存する
5. totalを表示する

という順番で処理されます。

---

## 9. プログラムは「処理の手順書」と考える

プログラムを理解するために、

**「コンピューター向けの非常に細かい手順書」**

と考えると分かりやすいです。

人間向けの手順書なら、

```text
カレーを作る

1. 材料を用意する
2. 野菜を切る
3. 肉を切る
4. 材料を炒める
5. 水を入れる
6. 煮込む
7. ルーを入れる
```

というように書きます。

プログラムも、

```text
1. データを受け取る
2. データを確認する
3. データを計算する
4. 結果を保存する
5. 結果を表示する
```

というように、処理の手順を記述します。

---

## 10. アルゴリズムとは

プログラミングを学んでいくと、

**アルゴリズム**

という言葉が出てきます。

アルゴリズムとは、簡単に言えば、

**「問題を解決するための手順や方法」**

です。

例えば、100個の数字の中から一番大きな数字を探す場合、

```text
1. 最初の数字を「現在の最大値」にする
2. 次の数字を見る
3. 現在の最大値より大きければ最大値を更新する
4. すべての数字を確認するまで繰り返す
5. 最後に残った数字を最大値として出力する
```

という方法を考えることができます。

これがアルゴリズムです。

プログラムは、このようなアルゴリズムをコンピューターが実行できる形にしたものだと考えることができます。

---

## 11. プログラミング言語とは

コンピューターに命令を書くためには、一定のルールに従って命令を記述する必要があります。

そのための言葉が、

**プログラミング言語**

です。

代表的なプログラミング言語には、

- Python
- JavaScript
- Java
- C
- C++
- C#
- Go
- Rust
- PHP
- Ruby

などがあります。

それぞれ文法や特徴が異なります。

---

## 12. なぜプログラミング言語が必要なのか

コンピューター内部では、最終的には非常に単純な形式の命令として処理が行われます。

人間がコンピューターの細かな命令を直接扱うのは大変です。

そこで、人間が比較的理解しやすい形でプログラムを書くために、プログラミング言語が使われます。

Pythonも、そのためのプログラミング言語の一つです。

# 02 コンピューターとプログラム

> **このページの学習目標**
>
> コンピューターがプログラムを使って処理を実行する仕組みを、初心者向けに理解します。

---

## 1. コンピューターは何をしているのか

コンピューターは、私たちの身の回りにたくさん存在しています。

例えば、

- パソコン
- スマートフォン
- タブレット
- ゲーム機
- スマートウォッチ
- 自動車
- 家電
- サーバー

などです。

見た目や用途は違いますが、基本的には、

**データを受け取り、プログラムに従って処理し、結果を出す**

という仕組みを持っています。

---

## 2. コンピューターは自分で考えているの？

コンピューターは非常に複雑な処理を行えます。

しかし、通常のコンピューターは、人間のように自分で目的を決めて自由に行動しているわけではありません。

基本的には、

```text
プログラム
↓
コンピューターが命令を実行
↓
処理結果
```

という仕組みです。

例えば、電卓アプリで、

```text
100 + 200
```

と入力すると、

```text
300
```

と表示されます。

これはコンピューターが勝手に考えているのではなく、

```text
数字を受け取る
↓
足し算をする
↓
結果を表示する
```

というプログラムに従って処理しています。

---

## 3. CPUとは

コンピューターの中には、

**CPU（Central Processing Unit）**

と呼ばれる重要な部品があります。

CPUは、コンピューターの計算や命令の実行を担当する中心的な装置です。

初心者の段階では、

**「CPUはプログラムの命令を実行する中心的な部品」**

と覚えておけば十分です。

例えば、

```text
計算する
比較する
データを移動する
命令を実行する
```

といった処理にCPUが関係しています。

---

## 4. メモリとは

コンピューターには、

**メモリ（RAM）**

という一時的にデータを保存する場所があります。

プログラムを実行するときには、プログラムや処理中のデータなどがメモリ上で扱われます。

例えば、

```text
100
200
300
```

という数字を使って計算している場合、その処理に必要なデータがメモリ上で扱われます。

メモリは、

**「現在作業しているデータを一時的に置いておく場所」**

と考えると分かりやすいです。

---

## 5. ストレージとは

コンピューターには、データを長期間保存するための場所もあります。

代表的なものが、

- SSD
- HDD

などです。

例えば、

```text
Pythonプログラム
写真
動画
文書
ゲームデータ
```

などを保存できます。

メモリとストレージは役割が違います。

簡単に考えると、

```text
メモリ
→ 作業中のデータを一時的に置く場所

ストレージ
→ データを長期間保存する場所
```

です。

---

## 6. プログラムが実行される大まかな流れ

Pythonなどでプログラムを実行するとき、内部ではさまざまな処理が行われています。

初心者向けに大まかに考えると、

```text
Pythonコードを書く
↓
Pythonを実行する仕組みがコードを解釈・処理する
↓
コンピューター上で処理が実行される
↓
結果が表示される
```

という流れです。

実際の内部処理はもっと複雑ですが、最初はこのイメージで問題ありません。

---

## 7. コンピューターは「データ」を扱っている

プログラムでは、さまざまなデータを扱います。

例えば、

```text
数字
文字
画像
音声
動画
ファイル
Webデータ
```

などです。

Pythonを学ぶと、

```python
name = "Taro"
age = 20
```

のようにデータを扱えるようになります。

ここでは、

```text
name → Taro
age → 20
```

という情報をプログラムの中で扱っています。

---

## 8. コンピューターは「0」と「1」を使う

コンピューター内部では、情報が非常に基本的な状態として扱われています。

代表的なのが、

```text
0
1
```

です。

このような0と1を使った表現を、

**2進数**

と呼びます。

例えば、私たちは普段、

```text
10
```

という数字を使います。

これは10進数です。

一方、コンピューター内部では2進数によるデータ表現が重要になります。

ただし、Pythonを学び始める段階で、0と1の仕組みを完全に理解する必要はありません。

まずは、

**「コンピューターは内部でデータを機械的に処理している」**

というイメージを持っておけば十分です。

---

## 9. ソフトウェアとは

コンピューターには、

**ハードウェア**

と

**ソフトウェア**

があります。

ハードウェアは、実際に触ることができる機械部分です。

例えば、

- CPU
- メモリ
- SSD
- キーボード
- マウス
- ディスプレイ

などです。

一方、ソフトウェアは、コンピューター上で動作するプログラムや関連するデータなどを指します。

例えば、

- Webブラウザ
- ゲーム
- メモ帳
- 動画編集ソフト
- Pythonプログラム

などです。

簡単に考えると、

```text
ハードウェア
→ コンピューターの「機械」

ソフトウェア
→ コンピューター上で動く「プログラム」
```

です。

---

## 10. OSとは

コンピューターを使うときには、

**OS（Operating System）**

という基本ソフトウェアが使われます。

代表的なOSには、

- Windows
- macOS
- Linux
- Android
- iOS

などがあります。

OSは、

- ファイルを管理する
- メモリを管理する
- プログラムを実行する
- キーボードやマウスなどの機器を扱う
- アプリケーションが動作するための環境を提供する

など、コンピューター全体を管理する重要な役割を持っています。

---

## 11. アプリとプログラム

普段使っているアプリも、基本的にはプログラムです。

例えば、

```text
電卓アプリ
↓
計算するプログラム

メモアプリ
↓
文字を入力・保存するプログラム

ゲーム
↓
ゲームのルールや画面などを処理するプログラム
```

というように考えることができます。

つまり、プログラミングを学ぶということは、

**コンピューター上で動くソフトウェアを作るための基本を学ぶこと**

でもあります。

---

## 12. プログラマーとは

プログラムを設計したり、コードを書いたり、動作を確認したりする仕事をする人を、

**プログラマー**

と呼びます。

実際の開発では、

```text
問題を考える
↓
必要な機能を決める
↓
処理方法を考える
↓
コードを書く
↓
実行する
↓
エラーを確認する
↓
修正する
↓
テストする
```

というような作業を繰り返します。

「コードを書くこと」だけがプログラミングではありません。

**問題をどう解決するか考えることも重要な作業です。**

---

## 13. バグとは

プログラムに意図しない問題があることを、

**バグ**

と呼びます。

例えば、本当は、

```text
100 × 3 = 300
```

と計算したいのに、プログラムを間違えて、

```text
100 + 3
```

としてしまった場合、

```text
103
```

になってしまいます。

このようなプログラム上の間違いもバグの一例です。

プログラミングでは、バグを見つけて修正する作業が非常に重要です。

---

## 14. エラーとは

プログラムを実行したときに、コンピューターが処理できない問題が発生すると、

**エラー**

が表示されることがあります。

例えば、Pythonで文法を間違えるとエラーが発生します。

エラーが出ることは、プログラミングでは珍しいことではありません。

むしろ、

**「エラーを見つけて原因を調べ、修正する」**

という作業は、プログラミング学習の重要な一部です。

---

```text
入力

プログラムに従った処理
```

また、コンピューターには、

```text
CPU

ストレージ
OS
```

などのさまざまな仕組みがあります。

# 03 Pythonって何？

> **このページの学習目標**
>
> 数あるプログラミング言語の中でPythonとは何なのか、どのような特徴があるのか、そしてPythonで何ができるのかを理解します。

---

## 1. Pythonとは

Python（パイソン）は、

**プログラミング言語の一つ**

です。

Pythonを使うことで、コンピューターにさまざまな処理を実行させるプログラムを作ることができます。

例えば、

```python
print("Hello, World!")
```

というPythonコードを書くと、

```text
Hello, World!
```

と表示できます。

これは、

**「Hello, World!という文字を表示してください」**

という命令です。

---

## 2. Pythonはなぜ人気なのか

Pythonにはさまざまな特徴があります。

特に大きな特徴の一つが、

**比較的シンプルで読みやすい文法**

です。

例えば、Pythonでは、

```python
print("こんにちは")
```

と書くことで文字を表示できます。

このコードを見ると、

```text
print
```

という部分から「何かを表示する処理なのかな」と想像しやすいでしょう。

このように、Pythonは初心者にも比較的理解しやすいような書き方ができます。

---

## 3. Pythonは初心者向けなの？

Pythonは、初心者が最初に学ぶプログラミング言語としてよく選ばれています。

理由の一つは、基本的なコードが比較的読みやすいことです。

例えば、

```python
name = "Taro"
print(name)
```

では、

```text
nameにTaroを入れる
↓
nameを表示する
```
